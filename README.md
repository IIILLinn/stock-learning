# 股海导航 · 系统学习炒股知识图谱

一个单文件交互式学习网站：32 个知识点 + 7 大模块的力导向知识图谱，
支持点击学习、先修/关联关系、学习路径、进度追踪（localStorage 自动保存）、全文搜索。

## 使用
- 在线访问：`https://<你的用户名>.github.io/stock-learning/`
- 或本地直接双击 `index.html` 用浏览器打开
- 本地起服务：`python3 -m http.server 8787` 后访问 `http://localhost:8787/`

## 说明
- 纯前端单文件，无任何外部依赖，可离线使用
- 学习进度保存在各设备浏览器本地，不会自动同步
